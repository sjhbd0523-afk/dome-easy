# dome-easy
고척돔 초보운전자를 위한 생성형 AI 주차 안내 프로젝트
### Dome-Easy — 고척돔 초보운전자 주차 도우미

**Dome-Easy는 고척돔 행사 방문 시 주변 주차 정보를 찾기 어려운 초보운전자가 자신의 조건에 맞는 후보를 비교하고, 검증된 지도 링크로 이동할 수 있도록 돕는 생성형 AI 프로젝트입니다.**

### 프로젝트 개요

- **프로젝트 유형:** 생성형 AI 기반 주차 정보 안내 프로토타입
- **해결하려는 문제:** 행사 당일 고척돔 주변 주차 정보가 여러 곳에 흩어져 있고, 초보운전자는 진입 난이도와 도보 거리 등을 한 번에 비교하기 어렵습니다.
- **목표 사용자:** 고척돔을 처음 방문하거나 복잡한 주차 환경이 부담스러운 운전자
- **프로젝트 목표:** 운전 숙련도와 방문 조건을 반영해 주차 후보와 추천 근거를 쉽게 확인하도록 지원합니다.
- **프로젝트 상태:** [기획 중 / 개발 중 / 시연 가능 / 완료 중 실제 상태 선택]

### 주요 기능

1. **초보운전자 맞춤 조건 입력 및 추천:** 운전 숙련도와 우선 조건을 바탕으로 후보를 비교합니다.
2. **주차 후보 정보·추천 근거 안내:** 진입 난이도, 요금, 도보 시간 등 확보된 데이터와 추천 이유를 보여줍니다.
3. **지도 앱 길찾기 연결:** 사용자가 선택한 장소의 검증된 주소를 바탕으로 지도 앱 링크를 제공합니다.
4. **행사 시간대 참고 안내:** 보유한 자료 범위 안에서 주의사항을 제공하며, 실시간 정보가 아닌 경우 이를 명확히 표시합니다.

### 시스템 구조

사용자 입력 → 웹/챗봇 UI → 백엔드(API) → 주차장 데이터 조회 및 후보 정렬 → LLM 추천 설명 생성 → 결과·주의사항 표시 → 지도 앱 링크 이동

- **프런트엔드:** [사용 기술 입력]
- **백엔드:** [사용 기술 입력]
- **생성형 AI 모델/API:** [실제 사용 모델 또는 서비스 입력]
- **데이터 저장 방식:** [JSON / 데이터베이스 / 기타 입력]
- **지도 서비스:** [네이버지도 / Google Maps 등 실제 연동 내용 입력]

### 생성형 AI 활용

LLM은 사용자의 자연어 조건을 이해하고, 시스템이 제공한 주차장 데이터에 근거해 추천 이유와 주의사항을 자연스럽게 설명합니다. 주차장 후보 필터링, 요금·운영 정보 검증, 지도 URL 생성은 가능한 한 구조화된 데이터와 프로그램 로직으로 처리합니다. 실시간 주차 API를 연동하지 않은 경우 실시간 만차 여부를 제공하지 않습니다.
